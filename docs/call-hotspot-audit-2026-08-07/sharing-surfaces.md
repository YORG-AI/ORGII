# Sharing Surfaces

Scope: backend adapter (replay/stream), download progress, share/import dialogs,
viewers indicator, address-comments run, fork/import, fetch retry plumbing.

Headline: the cleanest domain. Zero `setInterval` in scope; every paged path capped
(64×4096 events, 200×50 listings) with abort support; dialogs fetch once per open
behind claim/attempt guards; presence syncs identity-stable with zero fetch fan-out;
the @agent round waits on jotai signals with one 15-min deadline timer — no polling.

Note: `commentTaskRunner`/`CloudAgentRunnerCard` no longer exist in this tree; the
live path is addressCommentsRun.ts. `freshToken.ts:18` still references the absent
`buildDefaultCommentTaskRunnerDeps` (README P2 #15).
