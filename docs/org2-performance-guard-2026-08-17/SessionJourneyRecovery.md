# Session Journey recovery — performance guard

| Area                        | Verdict | Evidence                                                                                                                                                                                    | Change or reason kept                                                                                                                                                                                                                | Verification                                                                                                                                  |
| --------------------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Session review polling      | fix     | The contributor implementation used a fixed 5-second interval while the review panel was open, including hidden documents, and permitted overlapping requests                               | Replaced it with one visibility-aware recursive timeout. Hidden documents cancel the timer; visibility return triggers one refresh; a running request must settle before the next timer is scheduled; cleanup removes listener/timer | Scoped ESLint and TypeScript pass; rendered control contracts pass 8/8                                                                        |
| Stale async writes          | fix     | Session changes/unmounts could allow old snapshot/comparison promises to commit into a newer surface                                                                                        | Added request-generation invalidation to Session Journey controls and snapshot; cleanup invalidates outstanding work, and results commit only for the current generation                                                             | Snapshot contract proves stale session responses cannot overwrite the current session; Journey controls compile and pass rendered contracts   |
| Project tree enrichment     | fix     | Per-session Journey results rebuilt the complete visible tree once per resolved request                                                                                                     | Canonical project/session tree renders first; Journey loads use concurrency 6; resolved results update a Map and coalesce full tree rebuilds into one 16ms timer; generation cleanup prevents updates after reload/unmount           | Loader tests prove maximum observed concurrency is 6 and streaming delivery; project-tree rendered contract and build-tree tests pass         |
| Retained frontend state     | keep    | Component-local Maps contain at most one Journey state per loaded canonical session and are discarded with the Project Tree component                                                       | No app-lifetime cache or unbounded event history was added; refs are replaced on reload and the only scheduled render timer is cleared on cleanup                                                                                    | Source inspection plus unmount/generation guards; no heap measurement claimed                                                                 |
| Review queue worker         | keep    | Durable jobs are claimed transactionally by one consumer; notifications coalesce; provider failure does not kill the executor; shutdown stops the task; startup recovers stale running jobs | Keep the durable queue/outbox design because it prevents parallel claims and survives restart without frontend retries                                                                                                               | Agent-core Journey suite passes queue idempotency, concurrent claim, coalescing, failure recovery, startup reconciliation, and shutdown tests |
| Provider history projection | keep    | Visibility filtering runs at SQLite read/projection time using exact branch memberships and ancestor cutoffs, before provider reconstruction                                                | Keep source-boundary filtering to prevent loading sibling/parent-future transcript into provider context                                                                                                                             | Journey and persistence suites cover legacy history, mismatched membership denial, nested prefixes, sibling exclusion, and confirmed capsules |

## Lifecycle matrix

| Lifecycle state          | Session review panel                                         | Project tree enrichment                                           | Snapshot surface                                     | Review queue                                                 |
| ------------------------ | ------------------------------------------------------------ | ----------------------------------------------------------------- | ---------------------------------------------------- | ------------------------------------------------------------ |
| Visible/active           | Single-flight refresh every 5 seconds while panel is open    | Canonical tree first; six loaders maximum; 16ms render coalescing | One generation-guarded request per session selection | One executor; transactional single-consumer claim            |
| Visible/idle             | Same bounded cadence; no overlap                             | Stops after each session resolves; no recurring timer             | No recurring work                                    | Sleeps until notification/recovery wake                      |
| Hidden                   | Timer cancelled; no polling                                  | No recurring work after initial load                              | No recurring work                                    | Durable background work may continue only for queued reviews |
| Re-open / session switch | One immediate visibility refresh; old generations ignored    | New generation replaces Map; old callbacks ignored                | Old response ignored                                 | Existing durable state is reloaded/reconciled                |
| Unmount / shutdown       | Listener and timeout removed; requests invalidated           | Coalescing timer cancelled; generation invalidated                | Request generation invalidated                       | Executor shutdown test proves task exits                     |
| Repeated open/close      | At most one listener and timer per mounted controls instance | Component-local state is recreated and released                   | No retained cache                                    | Queue remains idempotent by job/review identity              |

Performance verdict: **blocked for release measurement, acceptable for draft review**. Code-level lifecycle invariants and focused tests pass, but real Tauri process CPU/RSS, a hidden-window idle observation, and a high-session-count rendered profile were not measured. No runtime performance improvement is claimed from typecheck or code shape alone.
