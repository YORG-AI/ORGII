# Context Lens — CANCELED / SUPERSEDED

**Status:** CANCELED (2026-07-25)

The proposed Context Lens is explicitly out of scope and is superseded by deterministic session navigation and the Progress Mind Map. Do **not** implement a Context Lens agent, context capture/proxying, or context-composition UI. Session progress views must derive from already persisted session/turn/tool/file-change records and must not call an LLM when opened.
