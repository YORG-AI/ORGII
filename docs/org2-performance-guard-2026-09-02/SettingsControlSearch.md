# Settings search performance guard

| Area                | Verdict | Evidence                                                                                                                                                 | Change or reason kept                                                                                                 | Verification                                              |
| ------------------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| Background work     | keep    | The global index is a synchronous projection built only when navigation visibility or locale changes; active-page collection runs only on query changes. | No polling, hidden-page rendering, retry loop, or idle subscription was added.                                        | Catalog parity and assembled-sidebar tests.               |
| Memory              | keep    | The sidebar memoizes one shallow catalog of roughly one item per schema key plus the current page’s supplementary rows while a query is non-empty.       | No page component trees, settings values, caches, or cross-window state are retained.                                 | Catalog uniqueness test and code inspection.              |
| Scope/isolation     | keep    | Global indexing reads static schema/navigation metadata. DOM work remains bounded to `data-settings-surface`, and reveal matches stable schema keys.     | Rows outside Settings and headerless rows remain excluded.                                                            | Outside-surface, headerless-row, and schema-key fixtures. |
| Selection lifecycle | keep    | A `MutationObserver` exists only after the user selects a result whose destination row has not rendered.                                                 | It disconnects on match, replacement, unmount, or a 2-second timeout. No observer exists while idle or merely typing. | Delayed-render reveal test and cleanup path inspection.   |
| Rendering/hot path  | keep    | Query filtering remains in the memoized dropdown model. The global catalog avoids mounting or traversing every Settings page.                            | Work scales with the schema item count and user keystrokes, not with hidden React trees or background time.           | Focused integration tests, typecheck, and ESLint.         |

Performance verdict: pass. The change replaces page-only indexing with a small static global projection and retains bounded, interaction-scoped DOM work. Live CPU/RSS measurement was not run because Computer Use was not authorized; no idle runtime path was introduced.
