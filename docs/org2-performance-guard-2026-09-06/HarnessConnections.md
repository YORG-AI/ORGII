# Harness connections lifecycle review

| Area                  | Verdict | Evidence                                                                                                                                            | Change or reason kept                                                                                        | Verification                                                                                                        |
| --------------------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------- |
| Background work       | keep    | Direct Settings reads occur on mount, visible focus, refresh and mutation invalidation; no polling loop                                             | Endpoint tests start only after user action; cc-switch panel scans only when explicitly opened               | DOM test observes two mounted consumers sharing a status request with no scheduled repeated request                 |
| Memory                | keep    | Pending status map has two harness keys and evicts settled requests; receipts cap at 64 with a 15-minute validity limit; test registry caps at four | No response cache, unbounded provider history, or per-session registry added                                 | Boundaries inspected in code; process RSS not measured                                                              |
| Scope/isolation       | keep    | Each hook owns a generation and removes subscriptions on unmount; cancelled tests drop the HTTP future; 45-second overall limit                     | Key/model/endpoint changes invalidate evidence; backend rereads selection before applying                    | Late cancelled completion and changed model DOM tests; resolver credential-revision test; stale config preview test |
| Rendering/hot path    | keep    | Shared editor subscribes only while mounted; no token-stream UI subscription                                                                        | Settings and detail share pending reads                                                                      | Concurrent mount test; no rendered-app frame/CPU measurement                                                        |
| Proxy lifecycle       | keep    | Startup creates a listener only for a persisted managed profile; explicit managed apply can start it                                                | Direct apply and status do not start a proxy; an already-started proxy retains its existing process lifetime | Configuration shutdown tests; listener lifecycle source inspection, no live Tauri measurement                       |
| Multi-instance writes | keep    | Per-target and manifest advisory locks; no watcher or retry loop                                                                                    | An overlapping writer receives a retryable error instead of waiting indefinitely                             | Lock exclusion test, transaction rollback/recovery and external-edit tests                                          |

| State                          | Expected behavior                                                                   | Observed evidence                                                                         |
| ------------------------------ | ----------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Unopened / direct-only startup | No new probes or scans; no proxy listener started                                   | Source inspection; real Tauri CPU/RSS not measured                                        |
| Visible idle                   | One status read per harness; no timer                                               | DOM concurrent-mount test                                                                 |
| Hidden                         | No focus-triggered read while document.hidden; no periodic read                     | Source inspection; real hidden-window measurement not run                                 |
| Active test / cancel           | Two small HTTP requests maximum per test, bounded bytes/time; cancel ends ownership | Protocol transport tests, cancellation generation DOM test; no real provider request used |
| Unmount / remount              | Listener removed, late completion ignored, fresh status read                        | Hook cleanup source inspection and DOM test teardown                                      |
| Repeated switch / exit         | Direct remains configured; proxy mode restores original when possible               | Owning-crate configuration tests and isolated native CLI fixture                          |
| Independent ORGII process      | Native targets coordinate even when ORGII_HOME differs                              | OS file-lock exclusion test; two real Tauri instances not run                             |

Performance verdict: **blocked** for real application measurement. Computer control was not authorized, so visible/hidden Tauri CPU/RSS, repeated-window resource counts, and dual-instance desktop measurements were not performed. Automated checks support bounded ownership and stale-result rejection; they do not establish a measured performance improvement. No cloud ingestion or sync transitions are claimed by this feature.
