# Claude Desktop connections performance review

| Area               | Verdict | Evidence                                                                                                                                  | Change or reason kept                                                                                                    | Verification                                                                     |
| ------------------ | ------- | ----------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- |
| Background work    | keep    | Status starts on mount, explicit mutation/refresh and visible focus; no timer/discovery watcher                                           | Only selected app editor mounts; previous listener is removed                                                            | Target selection and existing single-flight/focus tests                          |
| Memory             | keep    | Read map has three target keys and no retained response cache; existing probes cap concurrency at four, receipts at 64 with 15-minute TTL | Adds one finite target; no model discovery cache or proxy owner                                                          | Existing shared-read tests and source inventory                                  |
| Scope/isolation    | fix     | Endpoint, auth scheme and target affect receipt revision; Desktop files use isolated external home                                        | Old evidence cannot authorize another app/endpoint/auth scheme                                                           | Resolver tests, Desktop editor invalidation tests and isolated native-file tests |
| Rendering/hot path | keep    | No streaming UI subscription added; cards render only current app's saved keys                                                            | One selected app mounted; DS components reused                                                                           | Rendered target-selector test                                                    |
| Native I/O         | keep    | Config/profile reads and writes run on spawn_blocking; macOS version reads inspect fixed installation plist paths                         | No app launch; Windows policy read uses registry API; executable metadata probe has five-second timeout and kill-on-drop | Source review; Windows runtime not run                                           |

Lifecycle coverage: active/idle has no newly recurring tasks; unmount discards late actions/cancels tests; hidden focus does not refresh; endpoint/auth changes invalidate receipts; direct profiles have no running proxy dependency. Offline test failures use the existing bounded request timeout. Cross-target restore/apply and missing-file restoration use isolated filesystem fixtures. Account/org sync and transcript ingestion are outside this feature.

Performance verdict: blocked for native runtime measurements. Automated lifecycle invariants are covered, but visible/hidden CPU/RSS measurements, Windows subprocess behavior, and native Desktop Chat/Cowork/Code sessions were not exercised. No performance improvement is claimed. Computer control was not authorized and was not used.
