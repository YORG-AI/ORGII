# EffortSlider performance guard

Scope: the shared model-variant popover's effort input and decorative motion. Model parsing, variant resolution, Apply/Cancel, persistence, IPC, and provider behavior are unchanged. The user's latest clarification explicitly requests a compact control and many continuously moving particles, rather than drag-only animation. Continuous visible motion is intentional; hidden/closed motion is not.
