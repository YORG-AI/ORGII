# WorkItemPickerModal performance guard

| Area               | Verdict | Evidence                                                                                                                                                     | Change or reason kept                                                                                                                                                      | Verification                                                                                |
| ------------------ | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Background work    | keep    | The modal content and source hook mount only when open; workspace reads occur on mount or explicit refresh                                                   | No polling, retry loop, worker, or app-lifetime listener is added; shared Modal listeners and its single 100ms focus timer are disposed on close                           | Closed/open/request/close/reopen tests; immediate-close timer test; explicit retry test     |
| Memory             | keep    | Existing workspace snapshot cap remains 500 and visible filtering remains capped at 20; request promise clears on settlement                                 | Model moves unchanged; picker options, filters, and selected keys are component-local and released on close; existing GitHub TTL/LRU cache remains the sole provider cache | Existing model bounds/single-flight tests and 11 source-cache tests pass                    |
| Scope/isolation    | keep    | Content is keyed by repoId and repoPath; local requests use a monotonically increasing generation; the existing GitHub hook owns repository/credential scope | No branch loading, duplicate cache, or new identity keys; changing repositories resets picker state instead of retaining old selected provider rows                        | Repository-change test, late response after close test, existing cache-scope tests          |
| Rendering/hot path | keep    | The outer trigger only owns open state; selection filtering stays inside the mounted dialog                                                                  | Creator-wide expanded-picker updates disappear; no per-frame geometry work. Shared Modal queries current focusable controls only on opening and Tab events                 | Card/pill trigger identity, keyboard enabled-state tests, broader creator regression suites |

Lifecycle matrix:

| Dimension                                   | Required behavior and evidence                                                                                                                                                                                                  |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Startup / unopened / idle                   | No workspace request or source-hook mount until open; directly asserted by the reusable-modal and attachment tests                                                                                                              |
| Active / refresh                            | Search and source filtering operate on loaded options; Add commits selected available options across filters; refresh keeps available source rows and can recover errors; tested                                                |
| Closed / unmount / shutdown                 | Local response generation invalidates, component arrays are released, Modal removes listeners and cancels its delayed focus; closed-state DOM and focus behavior tested. An already-started shared request is allowed to settle |
| Hidden / focus return                       | No new recurring work; there is no visibility polling or refresh timer. Existing source-cache freshness behavior is unchanged. Actual hidden-window CPU/RSS not measured                                                        |
| Network failure / retry                     | Error from a failed source does not remove available rows from another source; refresh is explicit and loading disables refresh; error/retry case tested with API fixtures                                                      |
| Repository scope                            | Repo id/path change resets query and selection; the existing source hook is called for the new scope. GitHub credential/cache isolation is unchanged; its cache tests pass                                                      |
| Session / auth / org / instance / transport | No new durable session state, endpoint transport, workspace permission rule, account switch handler, or instance lifecycle. Real auth changes, isolated secondary processes, and transport were not exercised                   |

Stack verification: 49 tests passed in eight focused suites. Shared cache bounds/single-flight behavior and real-Modal focus/disposal are covered. The unchanged model and its tests move with the new modal. No new polling, worker, or app-lifetime cache is introduced.

Performance verdict: **blocked** for native Tauri visible/hidden CPU/RSS and real-provider latency measurements; unit-level loading, memory bounds, scope, and cleanup checks pass. Computer Use was not requested, so no desktop control was used and no measured runtime improvement is claimed.
