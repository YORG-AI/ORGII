Accessibility check: the shared `TabPill` renders labeled native buttons with the repository's established focus behavior; removing decorative tab icons and counts leaves the visible labels unchanged. Existing filter and toolbar buttons retain labels and keyboard reachability.

Design-system check: the shared `TabPill` exposes an explicit numeric outer-height prop so compact toolbar consumers can request the canonical 28px control height without duplicating wrapper CSS. Published header slots expose an opt-in joined-row contract and one canonical `pl-2` content inset, so panes neither override shell chrome nor duplicate alignment padding. No new color, spacing, shadow, or radius primitive was introduced.

Systematic sweep: `GitHubWorkItemSummary` and its `summary` frame prop have no remaining source references. No second GitHub Open/Closed selector or raw PR-detail tab button implementation remains. Published-header consumers no longer add an outer `pl-*`/`px-*` solely for slot alignment; URL-input icon padding and separate body/search-row padding remain intentionally local.
