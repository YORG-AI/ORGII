## Verdict summary

- Fix: 7
- Keep with reason: 2
- Abstract: 0
- Multi-file sweep candidates: 0

Accessibility check: project names remain the accessible navigation and tab labels, while the provider SVG is a visual identity marker in the existing icon slot. Removing the compact property row removes duplicate interactive controls without changing project navigation, title editing, descriptions, or the separately labeled properties-panel action.

Design-system check: the GitHub mark comes from the shared `IntegrationIcon` SVG map at the same 14px sidebar size used by other provider rows. The change introduces no new color, spacing, shadow, radius, or arbitrary-value primitive.

Systematic sweep: recent-project rows, sidebar search results, group-by-project overview rows, both Chat project-tab opening paths, the main Work Items overview, and the Chat project view were checked. Local project rows, non-project tab types, and the right-side properties panel are intentionally preserved.
