# Repository Spotlight Git-status removal architecture audit

Scope: make repository Spotlight lists simple by removing Git-status fetching, caching, attachment, and rendering. Preserve repository loading, search, selection ordering, manage actions, path display, workspace switching, and the selected-repository Source Control status path.

Acceptance: repository Spotlight items never request or carry Git status; no status badges render; no Spotlight-only provider, timer, batcher, cache, or retry logic remains; every repo-list consumer uses the same load → map → filter pipeline; existing repository and Source Control behavior remains otherwise unchanged.

Authoritative source: the central repository store remains the source for Spotlight repository rows. The removed status source was `gitApi.getGitStatus`, requested by `MultiRepoGitStatusContext` and written into `repoGitStatusCacheAtom`.

Root cause and producing path: repo lists were enriched for optional badges by a second background data pipeline. Opening repo-list consumers called `requestRefresh`, which scheduled batched Git-status requests, wrote condensed results to a cache, attached them to `RepoItem`, copied them into `SpotlightItemData`, and rendered badges in the shared row.

Source-level invariant: repository Spotlight types contain no Git-status field, and the shared repo-list hook depends only on repository state, the dedicated repository loader, and search filtering. It does not mount the full repo-selection hook or any Git/status dependency. This makes a future status request impossible without an explicit new type and data-flow change.

Historical remediation: no repository or Git data was malformed, and no persisted data cleanup is required. Existing local storage cleanup behavior was deliberately left unchanged; this change deletes active in-memory Spotlight status infrastructure only.

No Rust/backend module changed. Wire, initialization, and resolver layers were inspected for applicability and intentionally limited to the removed frontend call chain.
