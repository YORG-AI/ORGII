# iOS Remote shell performance guard

Scope: the native Web Remote entry, Tauri deep-link/auth bridge, account-scoped paired-device storage, and the shared Mobile Remote provider lifecycle.

| Area               | Verdict | Evidence                                                                                                      | Change or reason kept                                                                                                                                          | Verification                                                                                                 |
| ------------------ | ------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Background work    | fix     | The Tauri adapter owns one app-lifetime deep-link listener; the shared provider owns the foreground WebSocket | Register the deep-link listener before reading cold-start URLs, dispose it on `pagehide`, and keep the existing foreground socket teardown/reconnect lifecycle | Warm/cold callback, dedupe, and listener-disposal unit tests; real hidden/foreground iOS measurement not run |
| Memory             | fix     | Warm deep-link dedupe retains a `Map`; paired desktops retain a local account inventory                       | Cap deep links at 16 entries with a 60-second TTL; cap paired desktops at 20; cap native secure values at 64 KiB                                               | Unit tests cover deep-link dedupe/bounds, inventory bounds, and the Rust value bound                         |
| Scope/isolation    | fix     | Native auth and paired-desktop records are secure-storage keys                                                | Scope device inventory by encoded authenticated user id; allow only owned Keychain keys/prefixes; invalidate stale auth generations on new intent/unmount      | Account-isolation, serialized-write, warm callback, opener-failure, and Rust allowlist tests                 |
| Rendering/hot path | keep    | Device rows are derived from a bounded inventory and connection snapshot                                      | Reuse the shared `DevicesTab`; no polling, transcript copy, or native-only duplicate store was added                                                           | Component/selector tests and TypeScript typecheck; rendered iPhone measurement not run                       |

Lifecycle matrix:

| Resource                 | Start/active                                                                           | Idle/hidden                                                              | Identity transition                                                                               | Shutdown                                                                   |
| ------------------------ | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| Deep-link subscription   | Created once before cold-start URL hydration                                           | Event-driven; no timer or polling                                        | New callback increments the auth intent generation so late work cannot commit                     | Unsubscribed on `pagehide`; pending auth is generation-guarded             |
| OAuth/PKCE secure state  | Written for an explicit sign-in attempt                                                | No background work                                                       | Auth callback consumes the matching attempt; sign-out clears the session; storage is app-owned    | No retained process/resource                                               |
| Paired desktop inventory | Read or updated on pairing/selection                                                   | No scan or refresh loop                                                  | Key includes authenticated user id; selection writes are serialized                               | Bounded persisted data remains intentionally available for the next launch |
| Relay WebSocket          | Existing shared provider opens the selected desktop connection while the app is active | Existing provider disconnects on background and reconnects on foreground | Generation/state ownership prevents an old connection from becoming current after a device switch | Existing provider cleanup closes the socket                                |

Performance verdict: **blocked**. The bounded ownership and unit-level lifecycle invariants pass, but this host has no usable `iphoneos` SDK, so visible idle, hidden idle, foreground reconnect, CPU/RSS, listener count after repeated open/close, and real-device account-switch measurements could not run. Those iOS cells remain required before the stacked PR can be marked ready.
