Verdict counts: **fix 4**, **keep with reason 3**, **abstract 0**.

Accessibility check: parent rows retain button semantics, focusability, keyboard activation, disabled state, and disclosure state. Two-line rows use explicit leading so labels and subtitles fit without clipping. No color, focus, or content semantics changed.

Design-system check: all selectable navigation rows use the existing Tailwind `h-8` scale utility. Two-line content uses the standard `leading-4` and `leading-3` utilities. No arbitrary height, color, radius, or new interaction primitive was introduced.

Systematic sweep: the shared navigation menu, Settings root, session/workstation connector, header-navigation row, and legacy item/group blocks were checked together. All selectable sidebar rows now resolve to 32px; the remaining 28px sizes belong to section labels and toolbar/form controls.
