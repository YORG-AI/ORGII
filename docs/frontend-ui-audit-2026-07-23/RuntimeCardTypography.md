# Runtime card typography — frontend UI audit

Scope: Runtime > Usage KPI cards, Runtime > Quota account cards, and their section refresh controls. The routed `frontend-ui-audit` skill file was unavailable, so this report follows the repository's documented audit format and the existing report precedent in this audit batch.

| Line                                                                      | Element                                      | Verdict          | Reason                                                                                                                                                                                                                                                       | Suggested change                                                                                                                  |
| ------------------------------------------------------------------------- | -------------------------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| `UsageStatCards.tsx:33-35`                                                | Usage KPI values                             | fix              | The 24px hero values and 18px secondary-row values were visually oversized beside the denser Runtime quota cards. A 20px/16px scale keeps the intended emphasis while making the two views feel related.                                                     | Use `text-xl` for emphasized KPI values and `text-base` for the remaining values.                                                 |
| `UsageStatCards.tsx:49-54`                                                | Usage labels and paired request value        | fix              | The paired request value at 14px competed with the primary session count. The title already resolved to 12px, but used an arbitrary value instead of the standard utility.                                                                                   | Keep card titles at `text-xs`; reduce paired secondary values to `text-xs`.                                                       |
| `StartPageQuotaGrid.tsx:53-58`                                            | Quota account title and plan                 | fix              | The 11px account title and 10px plan were smaller than the Usage card typography. Increasing the title to the same 12px used by Usage and the plan to 11px improves cross-view consistency and readability.                                                  | Use `text-xs` for account titles and 11px/16px leading for plan text.                                                             |
| `StartPageQuotaGrid.tsx:75-89`                                            | Quota metric labels, reset hints, and values | fix              | Metric content at 10px was undersized relative to Usage-card supporting text. Increasing it one step preserves the compact quota layout without collapsing the hierarchy.                                                                                    | Use 11px text with 16px leading for each metric row.                                                                              |
| `StartPageQuotaGrid.tsx:42-75`                                            | Quota card internal spacing                  | fix              | The larger quota type made the former 8px padding and tightly stacked metric rows feel clamped. More padding and wider vertical gaps let the account header, metric labels, and progress bars breathe.                                                       | Use 12px card padding, an 8px header separation, 10px between metrics, and 4px between a metric label and its bar.                |
| `StartPageQuotaGrid.tsx:116-120,164-205`                                  | Quota grid responsiveness and gutters        | fix              | A fixed two-column layout squeezed card content in narrow chat panels, and its 8px gutter did not match the Usage card grid. | `StartPageQuotaGrid.tsx:172-194`, `SessionUsagePanel.tsx:260-268,336-355` | Section title and refresh controls           | fix              | Quota rendered its refresh action in a separate row from its title, while Usage offered no equivalent top-level refresh action. | Both card components                                                      | Card title weight and color                  | keep with reason | The Usage label describes a KPI category and remains regular `text-text-2`; the quota title identifies an account and remains semibold `text-text-1`. Matching size is desirable, while matching weight and color would erase their distinct semantic roles. | Keep the existing weight and color distinctions.                                                                                  |
| Both card components                                                      | Shared typography abstraction                | keep with reason | Both titles now use the standard `text-xs` utility directly. A new cross-module token for a single existing Tailwind utility would add indirection without preventing meaningful inconsistency elsewhere in the card hierarchy.                              | Keep the standard utility inline; abstract only if more card families adopt a complete shared type scale.                         |

Verdict counts: **fix 7**, **keep with reason 2**, **abstract 0**.

Accessibility check: text contrast tokens are unchanged, the smallest quota text increases from 10px to 11px, and both refresh actions use native shared buttons with localized aria labels, titles, disabled states, and visible loading animation.

Design-system check: card titles now use the standard `text-xs` utility in both components. Quota-card spacing uses the same `gap-3` grid gutter as Usage and existing Tailwind scale values internally. Both refresh actions use the shared tertiary ghost `Button` and refresh-spin hook; no new color, radius, or interaction primitive was introduced.

Systematic sweep: the Runtime Usage and Quota card families were checked together. Their title roles now share the same 12px size and their grids share 12px horizontal and vertical gutters; supporting scales intentionally differ by one hierarchy step to suit KPI and dense quota content.
