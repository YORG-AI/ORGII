# Quick setup acceptance cases

## Outcome and ownership

- First run asks only for language, appearance, and primary color in a fixed left-preview/right-settings layout; the preview selector is hidden from this surface.
- Preview layout is a local-only global preference managed by the `Cmd/Ctrl+0` preferences panel. It defaults to compact when no valid value has been stored.
- The compact preview's selected core surface and right-side file-content disclosure are component-local. They default to SDE Agent with file content collapsed on every mount and never perform real navigation or product mutations.
- Each preference writes through the same canonical Settings atoms used by the full settings page.
- Advanced theme presets, organizations, workspaces, Team Inbox, and product teaching stay inside the app.
- Settings owns the terminal `open | completed | dismissed` outcome, the one-time guide handoff, and education-only action milestones.
- Session and organization completion are derived from their authoritative product stores; guide state does not duplicate them.

## State machine

| State       | User event                       | Visible result                                                                 | Persisted effect                                                 | Next state  |
| ----------- | -------------------------------- | ------------------------------------------------------------------------------ | ---------------------------------------------------------------- | ----------- |
| Editing     | Change language/appearance/color | The current surface updates immediately                                        | Canonical preference write is queued                             | Editing     |
| Editing     | Change layout from global panel  | Only the left preview swaps between compact app and mascot visuals             | The local preview preference is persisted                        | Editing     |
| Editing     | Select a compact-preview icon    | The miniature swaps between SDE Agent, Team Inbox, and Work Items              | None                                                             | Editing     |
| Editing     | Toggle the compact file button   | A readable code column opens or closes beside the active miniature             | None                                                             | Editing     |
| Editing     | Get Started                      | Primary action enters loading, then Workstation opens                          | Completion marker and `guideHandoff: pending` persist atomically | Workstation |
| Editing     | Skip Setup                       | Actions disable while saving, then Workstation opens                           | Dismissed outcome persists; no guide handoff is armed            | Workstation |
| Closing     | Repeated finish/skip             | No second operation starts                                                     | No duplicate completion write                                    | Closing     |
| Closing     | Save fails                       | Error is shown and preferences remain visible                                  | Completion/handoff is not published                              | Editing     |
| Workstation | Pending guide mounts             | Five-task guide opens                                                          | Handoff becomes `shown`                                          | Workstation |
| Workstation | Handoff save fails               | Current guide remains usable                                                   | `pending` remains, so a later remount retries                    | Workstation |
| Workstation | Create organization task         | Add ORG opens on Cloud + Create and focuses/spotlights the name field          | None until the cloud roster confirms successful creation         | Workstation |
| Workstation | Invite task with manageable ORG  | ORG management opens on Members; create action is spotlighted                  | None until the real invite mutation succeeds                     | Workstation |
| Workstation | Team-usage task with cloud ORG   | Runtime opens for that organization on Members; the tab control is spotlighted | The viewed education milestone persists                          | Workstation |
| Workstation | Select a development simulation  | The independent test panel changes guide routing and Members presentation      | None; the runtime-only override resets on process restart        | Workstation |
